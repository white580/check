# キャラクター画像保存フォルダー

このフォルダー（`assets/characters/`）には、子供たちが大好きな有名なキャラクターやアニメキャラクターなどの画像ファイル（`.png`, `.jpg`, `.svg`, `.gif` 等）を自由に保存しておくことができます。

## 画像の追加手順

1. 好きなキャラクター画像をこの `assets/characters/` フォルダーに保存します。
   - 例: `pokemon.png`, `mario.png`, `chiikawa.png`
2. アプリの画面右上にある **「⚙️ 先生用設定」** ボタンを押します。
3. **「🎨 キャラクター画像カスタマイズ」** の項目で、設定したいレアリティ枠（枠① 40% ～ 枠⑥ 0.1%）の **「画像ファイル選択」** ボタンを押します。
4. このフォルダー内の画像を選択すると、自動的に読み込まれます！
5. キャラ名や褒め言葉（例: 「やったね！」「ぜんぶOK！」）を入力して **「追加」** ボタンを押せば登録完了です！
