# ☀️ 朝の提出チェッカー (Morning Submission Buddy)

小学校などの学級において、朝の登校時に児童が電子黒板等のタッチパネル操作で提出物を自発的かつ楽しく自己管理できるWebアプリケーションです。

---

## 🌟 アプリの特徴・機能

1. **16:9 横画面・スクロールなし全員一括表示**
   - 画面を一切スクロールせずに、クラス全員の提出状態が一目で確認できます。
   - 児童数（10人～40人以上）に応じて、カードの大きさやフォントサイズが自動調整されます。

2. **ガチャ風ランダム確率（6段階レアリティ）でキャラクターが出現**
   - 提出物マスをタッチすると、以下の確率でキャラクターが「OK！」「やったね！」などの褒め言葉と一緒に飛び出します！
     - 枠① (40%): ノーマル 1
     - 枠② (30%): ノーマル 2
     - 枠③ (20%): レア
     - 枠④ (9%): Sレア
     - 枠⑤ (0.9%): SSレア（特別演出）
     - 枠⑥ (0.1%): UR激レア（1000回に1回！豪華金ピカオーラ＆お祝いファンファーレ！）

3. **各枠に最大10体まで有名なキャラクター画像を自由に登録可能**
   - 画面右上の「⚙️ 先生用設定」から、画像ファイル（.png, .jpg, .svg, .gif）を簡単に選択して登録できます。
   - 合計最大60体のキャラクターをプール可能。

4. **間違えて押してもトグルで消える**
   - タッチしたマスをもう一度押すと消去されます。

5. **ワンタッチ「ぜんぶOK」ボタン**
   - 提出物をすべて持ってきた子が1回押すだけで、自分のマスをすべてタッチ済みにできます。

6. **全員完了で豪華な紙吹雪演出**
   - クラス全員が提出を完了すると、画面いっぱいに紙吹雪（Confetti）が舞い、お祝いファンファーレが流れます！

7. **先生向け便利機能**
   - 名簿の一括テキスト登録
   - 提出物項目の変更（連絡帳、宿題ノート、音読カード、健康観察票など自由設定）
   - 「あしたの朝用にクリア」リセット機能
   - 未提出者確認サマリーモード

---

## 🚀 使い方・起動方法

1. `index.html` をブラウザ（Google Chrome, Edgeなど）で開きます。
2. 電子黒板やディスプレイで全画面表示（キーボードの `F11` キー）にしてご活用ください。
